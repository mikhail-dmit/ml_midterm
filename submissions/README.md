## Final choice — experiments closed

The user designated **`submission_007.csv`** as final and stopped experiments.
Its file hash, configuration and validation counterpart are frozen in
**`final_selection.json`**. It improves over 006 by **0.00045 public /
0.00132 private** and is best on both recorded scores.

**`submission_007.csv`** keeps every 006 component/model and eight-week recency
setting unchanged. It changes RRF weights from MF=.5/PPR=.5/rules=.125/pop=.125
to **MF=.5/PPR=.5/rules=.1875/pop=.0625**. The total auxiliary budget stays .25;
depth five, offset zero, candidates and four-user cold fallback remain fixed.
It won a predeclared thirteen-new-configuration study on primary local MAP:
**0.37652771 all / 0.41177101 template**, versus 006's **0.37601075 / 0.41099420**.
Both paired intervals include zero, so it is a cautious attempt rather than a
clear improvement. Selection loads no Kaggle score ledger or test-submission
CSV. See `reports/recency_extension/README.md` and `reports/submission_007/README.md`.
